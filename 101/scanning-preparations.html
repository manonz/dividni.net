After (or before) the test / exam: Get prepared for OMR sheet scanning and grading

There are a number of things you can prepare before the test or exam date in order to expedite grading and giving feedback after the test or exam.

Getting ID-name and ID-login name mapping files ready

We're assuming here that your class is a Canvas class and that you know how to export and import a Canvas Gradebook in CSV format.

To support your scan post-processing and eventual feedback mailout you need a file with student names and university ID numbers, and one with university ID numbers and login names, respectively. To expedite scan post-processing and grade return, you can prepare these in advance. Here is how:

  • If you have access to Canvas, grab a gradebook export (CSV file) from the Grades menu of your class in Canvas. Then upload the CSV file and use the left and centre button to generate the files IDs.txt (for the scan post-processing) and student-list.tsv on the Dividni Canvas Gradebook Utility page.
  • If you do not have access to Canvas (i.e., you manage your grades differently), you can generate the two files as follows:
    • IDs.txt is a tab-separated file without headers, in which the first column contains the student ID number and the second column contains the student's name (ideally enclosed in double quotes just in case students have managed to smuggle tabs into their names). If you have a class list in CSV or Excel format, you can create this file easily from the spreadsheet and save it as "Text (Tab delimited) (*.txt)".
    • student-list.tsv is also a tab-separated file without headers, in which the first column contains the student ID number and the second column contains the student's login name (which we assume is identical to the username in their official university e-mail address). If you have a class list in CSV or Excel format, you can create this file easily from the spreadsheet and save it as "Text (Tab delimited) (*.txt)" - but change the extension from .txt to .tsv when saving the file.

Installing the software required to give feedback to the students (University of Auckland only)

In order to give feedback to students, the command-line version of Dividni contains a tool that allows you to e-mail feedback to the students. The text files with the feedback will be in the result folder of the ZIP file that will be returned to you by the McqGrader (the online interface that lets you grade the scanned OMR sheets in conjunction with the ground truth answers). Using this tool (Windows PCs only - ask us for Linux / Mac) requires a bit of preparation as follows (UoA staff only):

  1. Installation of the latest Microsoft .NET SDK. You'll probably want the x64 Windows installer. Note that unless you have software installation privileges for your PC, you will need to request this from Connect at the moment. Note that the current version of the SDK is 10.0 and that the version 4.8 SDK available via Software Center on your PC is too old (we have requested an update there).
  2. Next, create a folder called Dividni in your C:\ directory.
  3. Then, download the Dividni ZIP file from here.
  4. Open the ZIP file, highlight all files with CTRL+A, then copy them with CTRL+C, and paste them with CTRL+V into the Dividni folder you created above.
  5. Right-click on a blank area in the Dividni folder and select "Open in Terminal".
  6. In the black terminal window that opens, enter the command dir | Unblock-File and execute it with the Enter key.
  7. Download the mailout powershell script (mailout.ps1).
  8. Unblock mailout.ps1 as follows:
    1. Right-click on the file and navigate to the bottom of the context menu.
    2. Click on "Show more options ..."
    3. At the bottom of the new menu, click on "Properties".
    4. In the menu that opens, tick the box next to "Unblock" and click on OK.
  9. For later: Once you have done your scanning and grading, you can copy the mailout.ps1 script into the folder that also contains the result folder of the extracted ZIP file from the McqGrader. Also copy the student-list.tsv file from above into that same folder. You can now start the mailout by right-clicking on mailout.ps1. It will ask you about your course and your assessment, and will then do the mailout for you. (Note: Your machine must be on VPN or the wired university network for this, not just on UoA-WiFi!)

Giving the scanning software permission to access your OneDrive, Dropbox or Google Drive

Last but not least (UoA staff only), doing a test scan of an arbitrary document a few days before the assessment speeds things up on the day, at least if you're planning to scan to OneDrive, Dropbox or Google Drive from one of the FollowMe printer/scanner/copiers that the university has pretty much everywhere. The reason is that the software that places the scans there - PaperCut MF - needs your permission to do so. By scanning the document to OneDrive, Dropbox or Google Drive, you trigger this approval process. A few minutes after scanning, you should find an e-mail from PaperCut MF in your inbox requesting permission. Follow the instructions in the e-mail, and see your scanned document appear in the folder Apps\Scans for PaperCut MF soon thereafter. Once you have given permission, you shouldn't have to give permission again for a while.
