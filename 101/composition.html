All ready? Composing a Dividni MCQ test or exam

First, you will need to have your ingredients together:

  • Your questions, in one or more question banks.
  • Your prologue (cover sheet / title page), in the Document Bank.
  • Any epilogue (appendix) with actual content, also in the Document Bank.
  • Your answer sheet (such as the OMR sheet that comes with the DIVIDNI101 demo)

Start composing an exam by hitting the "Create Exam" button in the top right corner of the right window.

You will first be asked to pick the questions for the exam.

Once you have selected these, Dividni brings up the exam configuration dialog.

The configuration dialog asks for:

  • The course code that this exam is for, e.g., COMPSCI 215. This will get propagated onto the page headers and the OMR sheet when the PDF preview and final versions get generated.
  • A label / designator for that exam under which it will be listed in the Dividni UI. This could be something like COMPSCI 215 Test 1 S1 2026 to tell it apart from other tests, final exam, semesters or years.
  • The date of the assessment. This will get propagated onto the OMR sheet when the PDF preview and final versions get generated.
  • The prologue (cover sheet) from the Document bank that you want to use. Copy the sample cover sheet to a new and more descriptive file name in the Document bank, then adapt it with the editor there for your course and assessment.
  • Any epilogue (appendix) you want to use. If you haven't got an appendix, leave this unselected, if you need the empty page appendix, you can add this in later.
  • The answer sheet (OMR sheet) you want to use, also from the Document bank.
  • The LaTeX system you want to use - ignore this unless you want to use formulas and have a preference for a particular system.
  • Whether you want to operate in proof mode. If you tick this box, the preview will show *** next to the "correct" answer option in Truth questions and next to "correct" statements in XYZ questions (note that if an XYZ question does not show any *** next to any of the statements, it means that all three statements are "incorrect").

Hit "Preview" and the window will show your selected questions on the left and, after a few seconds, the PDF preview of script version 0 on the right (it'll say 000000000098, but the 98 are just checksum digits, the actual version number is to the left of the 98).

Getting the pagination right

Student experience commands that we:

  • Don't break questions across pages if at all possible, and
  • leave enough space for them to do their working (calculations etc.)

Practical printing necessity commands that each script have exactly the same number of pages (including prologue/cover sheet, appendices and OMR sheet) and that this number be even, i.e., a multiple of 2.

Default Dividni behaviour is that question instances in different script versions differ in length (sometimes answer options for a question take up a different number of lines) and that each question follows immediately after the other.

It's up to us to:

  • Drag questions around on the left to change the order in which they appear.
  • Insert page breaks that:
    • avoid question spillover onto the next page and
    • ensure sufficient working space below questions.
  • Insert an epilogue that brings the total number of pages up to an even number, even if that epilogue is just an empty page.

Start with the page breaks from the front. In the left window, click on "Add page break" and then drag the page break from the end of the questions to where you need it. Add as many page breaks as you need.

A page break at the end of the questions won't work, so in order to bring up the total number of pages to an even number, your epilogue (appendix) needs to have the right number of pages:

  • If you are not yet providing an appendix, go to the Assessment Setup and select the empty page appendix as your epilogue.
  • If you are already providing an appendix with other material and the number of pages is not right, go to the Document bank, open the empty page appendix for editing, copy its contents, then open your actual appendix for editing and paste the material from the empty page appendix at the end. This should fix it.

 You are now ready to produce your exam.
