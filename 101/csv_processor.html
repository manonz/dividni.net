Dividni Canvas Gradebook Utility

Use this page with a Canvas Gradebook export CSV file to:

  • Generate the ID file IDs.txt required for use with the Dividni OMR Processor to check student IDs from the scan against the class roll during scan post-processing.
  • Generate the AUID-to-UPI map file student-list.tsv required to send feedback to the class.
  • Merge the graded Dividni scan results in scan_result.csv with the Canvas Gradebook (for subsequent Canvas Gradebook Import).
