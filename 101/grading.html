Grading the OMR scan results

The output of the Dividni OMR Processor after the post-processing step is a text file which you download from the OMR processor page. This will generally be a file whose name ends in ...updated.txt or somesuch.

From preparing your Dividni test, you should also still have a ZIP file with the ground truth answers that the Dividni Exam Generator web UI made you download just before the PDF file(s) with the actual test/exam scripts. This file will normally have a complex name that just ends in ...-Answers.zip and identifies the test or exam as well as the date and time on which the answers were generated.

Got both of these? Then you have all the ingredients you need.

Head to the Dividni MCQ Grader page and upload those two files. Before upload, you will also have the opportunity to tick three checkboxes:

  • Include feedback in results: By default, the feedback file that the Dividni MCQ Grader generates for each student only identifies the answer option that the student chose for each question. By ticking this box, the Dividni MCQ Grader also includes a "Well done!" or an "Incorrect" alongside each answer.
  • Include correct answer in feedback: Ticking this option also tells the student what the correct answer option would have been for questions for which they chose the wrong answer. We generally recommend not ticking this as it tends to encourage memorising of answers downstream as opposed to working them out.
  • Use McqGraderLite: This option is only for those who use Dividni OMR sheets without full individualisation. In fully individualised Dividni tests/exams, the OMR sheet version number printed on and then scanned from the OMR sheet includes an added two-digit checksum, whereas the ground truth answer files only contain the base version number without the checksum in their filename. Users who have generated their own multi-version scripts and who have produced custom OMR sheets and ground truth answer files here have sheets without checksums. Ticking this box instructs the MCQ Grader not to expect a checksum from the OMR sheet in this case and match OMR sheet version number to ground truth answer file name as is.

A few seconds after hitting the "Upload" button, the MCQ Grader offers you a download link to a ZIP file with the grading results. Download this file and extract it.

Inside the ZIP file, you will find:

  • A folder result with a feedback text file for each student, with the filename being the student ID followed by .txt. UoA staff with Windows machines: You can use this folder to give feedback to your students at question level.
  • A text file with the file name extension .log. This contains, in each line, the student ID followed by a tab character followed by the version number (with checksum where applicable) of the student's OMR sheet, followed again by a tab character, and eventually the number of marks that the student scored.
  • A CSV file (comma-separated spreadsheet file) that opens with MS Excel. Each row corresponds to one student. In its first column, this file has the student ID, the remaining columns in each row are the marks that the student earned for each question, in order of question number. Note there is no column for total marks. This file has three primary uses:
    1. Marks adjustment: For example, if one question turns out to have had no correct answers, or more than one correct answer, or was ambiguous, you may wish to give students the benefit of the doubt and full marks for this question by entering the full number of marks for the question into the column in all rows of the file.
    2. Mark upload to Canvas (UoA only - and institutions whose Canvas gradebook exports have the same format as those at UoA): See how you can merge this CSV file with a CSV file from the Canvas gradebook download in order to upload marks to the Canvas LMS.
    3. Analyse the difficulty of your questions by adding up the marks in each column, dividing by the number of marks for the question and the number of OMR sheets scanned, and expressing the result as a percentage.
