Grade upload to Canvas

You can prepare for this before the test or exam date in order to expedite grading and giving feedback after the test or exam.

We're assuming here that your class is a Canvas class and that you know how to export and import a Canvas Gradebook in CSV format.

If you have access to Canvas, ensure that the test or exam has been configured as an "Assignment" there. Then grab a gradebook export (CSV file) from the Grades menu of your class in Canvas and save it to your computer.

Once you have completed grading with the MCQ Grader and have the CSV file with each student's marks for each question available, proceed as follows:

  1. Upload the gradebook export CSV file on the Dividni Canvas Gradebook Utility page.
  2. Click on the right button "Merge Dividni MCQ Grader Output".
  3. This adds a new section "Merge MCQ Grader Output". It first shows a drop-down list of assessments. Choose the test or exam you want to upload the marks for.
  4. Below the drop-down list, where it says "Upload scan_result.csv", upload the CSV file from the ZIP file that MCQ Grader gave you.
  5. The page will now download an updated gradebook CSV file to your browser (look in the download folder if it does not prompt you where to save it).
  6. Go to the Grades menu of your class in Canvas and click on "Import" at the top right. Choose the updated gradebook CSV and hit "Upload data". Then follow the instructions that Canvas gives you.

Giving feedback to the students (University of Auckland users on Windows machines only)

Make sure you have installed the required software and set it up as described here. Copy the mailout.ps1 script into the folder that also contains the result folder of the extracted ZIP file from the MCQ Grader. Also copy the student-list.tsv file you have created from your gradebook export CSV file on the Dividni Canvas Gradebook Utility page into that same folder. You should now have a folder that contains:

  1. The result folder of the extracted ZIP file from the MCQ Grader with the individual feedback text files.
  2. The mailout.ps1 script.
  3. The student-list.tsv file.

For the following, ensure you are on a wired connection at the university or on university VPN.

In a Windows explorer window, navigate to that folder. Right-click on mailout.ps1 and select "Run with PowerShell". A black terminal window will open. The script will prompt you to enter your course code and then your assessment title. Enter these and - if all has been correctly configured - watch the magic as your students will be e-mailed one by one. Note the e-mail will appear to come from postie.dividni@aucklanduni.ac.nz rather than your own e-mail address.
